# AI Concept Compass — greenfield certification repository

This repository starts with product discovery and delivery contracts before any
application source is introduced. The first commit intentionally contains only
shape notes, PRD, business/technical requirements, architecture decisions,
roadmap, test strategy and an implementation plan.

The product will be a Polish-language learning application for AWS Certified AI
Practitioner. It will detect gaps between declared confidence and self-assessed
results and recommend the next concept deterministically, without an LLM in the
MVP.
